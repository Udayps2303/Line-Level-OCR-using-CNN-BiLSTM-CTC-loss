# step 1
create a "Project" folder and put all the files inside interruption

# step 2 
in the "Project/input/books/pdf" save all the books pdf in sequence like 1.pdf, 2.pdf, etc... and in
"Project/input/books/GT" save all book GT's in sequence like 1.txt, 2.txt, ....

# step 3
now download the HiSAM repo from github and put it inside "Project" folder,
then download "Project/Hi-SAM/pretrained_checkpoint/line_detection_ctw1500.pth" and 
"Project/Hi-SAM/pretrained_checkpoint/sam_vit_h_4b8939.pth" and then run x.py to get all line level images(GPU Required)

# step 4
then run Project/create_final_mapping.py to create mapping file and then run 
Project/sorting_new_map.py as created map is not map_sorted

# step 5
Then if you want you can run
Project/image_preprocessing_VIT.py for seeing the examples of preprocessings can be done
Project/image_size.py for seeing stats of line images 
Project/map_stats.py for seeing stats of the mapping file
Project/Line_extraction_using_teseract.py ( Not Recommended )

# step 6
Create a conda environment with python 3.10 and install dependencies from "requirements.txt"

# which decoder to use and how to switch
a) in config.yaml file change between the decoder you want to use.
b) go through the infer.py and you can see the switches to do for the respective decoder.
c) use evaluate.py for greedy decoding and evaluate_for_beam.py for beam.

# step 7
Build the charset 
run - python utils/build_charset.py --config config.yaml

# step 8
Start training
run - python train.py --config config.yaml
To resume after interruption: run - python train.py --config config.yaml --resume checkpoints/best_model.keras

# step 9
To Evaluate a trained model on the test set and print CER/WER.
run - python evaluate.py --config config.yaml --checkpoint checkpoints/best_model.keras

# step 10
To infer on new unseen image run - 
# Single image
python infer.py --image /path/to/new_line.png

# Whole directory of line images
python infer.py --dir /path/to/new_book_lines/
this will create multiple predictions so to get the average of all run and before running update the txt file 
name in the code- python compute_cer_&_wer.py
